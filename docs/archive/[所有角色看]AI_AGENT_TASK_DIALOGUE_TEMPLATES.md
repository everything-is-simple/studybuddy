# StudyBuddy AI Agent 任务对话与执行模板

> **版本**：v2.2
> **更新日期**：2026-09-28
> **适用范围**：StudyBuddy 的浏览器验证、API 验证、文档修改、代码修改、数据处理和运行排障任务。
> **配套专项文档**：`H:\studybuddy\docs\[测试看]BROWSER_VERIFICATION_TASK_TEMPLATE.md` 用于浏览器专项细节；该专项模板必须遵守本文件的 P0-P4、路径、状态和证据规则。

**⚠️ 重要边界声明（2026-09-28 新增）**

本文件是**测试与验证任务的执行协议**，不是产品设计指南。

**本文件的职责范围**：
- ✓ 指导 AI Agent 如何执行测试、验证、审核任务
- ✓ 确保测试证据可追溯、可复现、不扩大范围
- ✓ 防止测试任务中的瞎做、假报、污染正式数据

**本文件明确不管的事**：
- ✗ 产品功能设计（什么功能对用户有价值）
- ✗ 用户体验设计（用户愿意每天打开什么样的界面）
- ✗ 交互流程设计（用户完成一次学习需要几步）
- ✗ 视觉设计（颜色、动画、反馈、鼓励）

**关键区分**：
- **测试辅助属性**（`data-od-id`、详细 `aria-label`、`title="[1] 导入文件夹..."`）**只为测试脚本服务**，不应成为产品界面的主导设计思路
- **产品界面的第一用户 = 真实人类**（家长、孩子），不是 Playwright 和审核 Agent
- **好的产品** = 用户愿意每天打开；**通过测试的产品** ≠ 好的产品

**如果你正在设计产品功能或用户界面**，请先读 `docs/[产品看]BUDDY_EXPERIENCE_DESIGN.md`（用户体验设计指南，待创建），而不是本文件。

本文件是执行协议，不是建议清单。任务 Prompt 未填写必填字段、使用模糊词、没有可核验证据路径，或要求替换指定工具/命令/路径时，Agent 必须在 `P0` 阶段返回 `BLOCKED`，不得进入操作阶段。

## 1. 不可覆盖的执行规则

1. **先读后做**：Agent 必须先读取 Prompt 指定的真实文件、目录、代码、页面或运行状态，再说明现状；不得凭记忆、模板示例或推测补齐缺失内容。
2. **原路径优先**：Prompt 指定的工具、命令、URL、端口、数据根、输入文件和输出目录必须原样使用。指定对象不可用时，状态只能为 `BLOCKED`；Agent 必须列出阻塞对象、实际错误和等待的确认事项，不得自行替换。
3. **阶段不可跳过**：任务依次经过 `P0`、`P1`、`P2`、`P3`、`P4`。未完成前一阶段，不得声称后一阶段完成。
4. **真实执行**：任务要求点击、输入、启动、停止、保存、导入、导出、调用或修改时，必须执行对应动作。读取 HTML、提取按钮清单、生成脚本、运行静态检查都不等于真实点击或真实业务操作。
5. **副作用分级**：导航和只读检查可以执行；创建、修改、删除、归档、永久删除、保存凭据、调用真实 Provider、发送 Email/飞书等动作，必须在 Prompt 中逐项列入“允许写入/允许副作用”并取得本次任务授权。未列入即禁止执行。
6. **证据先于结论**：每个 `PASS`、`FAIL`、`LIMITED` 或 `NOT_APPLICABLE` 必须关联命令/操作、时间、退出码或页面结果、证据文件路径。没有证据只能写 `NOT_VERIFIED`。
7. **不泄露秘密**：API key、Token、真实教材 token、Provider 原始响应、密码、Cookie、完整个人资料和原始教材正文不得写入 Prompt、日志、截图、Git、报告或聊天回复。证据使用 `[REDACTED]`、`[SET]`、`[EMPTY]`。
8. **范围不可扩大**：只读取/写入 Prompt 的路径和文件。发现需要新增文件、清理文件、修改配置、修改源码、调用外部服务或扩大浏览器页面范围时，先 `BLOCKED` 并等待确认。
9. **停止条件优先**：发生工具不可用、路径不可访问、端口不符、进程身份不符、服务健康检查失败、真实页面与手册不一致、需要未授权副作用、证据无法落盘等情况时，立即停止相关步骤并报告；不得继续“猜测完成”。
10. **结论边界**：`implemented`、`configured`、`available`、测试通过、隔离环境通过都不能自动写成 `real-pass`。只有本次任务的真实目标、真实路径和真实输入均执行成功，才可写 scoped `real-pass`；未覆盖范围写 `not_verified`。

`python -m backend.app serve` 是实现层的单进程入口，不是本模板中替代启动脚本的路径。Prompt 已指定启动脚本时，Agent 不得改用该命令；只有 Prompt 明确指定并授权时才可使用。

## 3. 统一阶段、状态和报告字段

### 3.1 执行阶段

- **P0 任务边界确认**：读取任务 Prompt 和引用文档；列出角色、目标、范围、允许读写、工具、命令、输入、输出、禁止项和停止条件。缺字段返回 `BLOCKED`。
- **P1 真实状态读取**：读取指定的真实文件/目录/代码/页面/进程/端点；记录时间、路径、版本或安全摘要。P1 不得修改目标对象。
- **P2 真实操作执行**：按 Prompt 的原顺序和原工具执行已授权动作；每个动作单独记录结果。未授权动作立即停止。
- **P3 证据核对**：检查证据文件存在、可读、与操作一一对应；复核退出码、HTTP 状态、页面状态、数据库状态或文件 diff。
- **P4 交付与结论**：只报告证据覆盖的范围；列出未执行、阻塞、未验证和下一步确认事项。

### 3.2 统一状态

`PASS` = 目标步骤已真实执行且预期结果和证据均满足。
`FAIL` = 已真实执行但预期结果不满足。
`BLOCKED` = 前置条件、工具、路径、权限或授权缺失，按停止规则未继续。
`LIMITED` = 已执行但证据或覆盖范围低于完整验收要求。
`NOT_APPLICABLE` = Prompt 明确说明该项不适用，并给出理由。
`NOT_VERIFIED` = 本次没有足够真实证据，不得推断为通过。

### 3.3 证据最小字段

每条操作至少记录：`task_id`、`phase`、`timestamp`、`actor`、`tool`、`exact_command_or_action`、`input_scope`、`result`、`status`、`evidence_path`。日志不得记录秘密和完整原始响应。

### 4.1 浏览器任务必填补充

浏览器任务必须额外填写：

- 浏览器和显示模式：例如 `Playwright + Chromium + headless=false`；不可用时 `BLOCKED`，不得改用 curl、API 请求、HTML 解析或 headless 代替真实点击。
- 页面清单：每个页面的完整 URL、进入方式和退出方式。
- 元素定位：每个按钮/链接/输入框的可见文字、稳定选择器或 ARIA 名称；“所有按钮”必须定义为某页面加载后可见且可操作的按钮集合。
- 操作清单：逐项列出点击、输入、提交、刷新、返回、下载、归档、删除等动作及是否允许副作用。
- 等待条件：具体 URL、可见文本、元素状态、HTTP 状态或任务状态；不得只写“等待完成”。
- 失败证据：错误文本、页面截图、URL、控制台/网络摘要和日志路径；不得保存密钥或完整敏感响应。
- 浏览器专项参考：先读取 `H:\studybuddy\docs\[测试看]BROWSER_VERIFICATION_TASK_TEMPLATE.md`；该文件不可用时停止并报告。

### 4.2 文档修改任务必填补充

文档修改任务必须额外填写：

- 修改文件绝对路径清单；未列出的文件禁止修改。
- 每个文件的读取范围、修改区段和保留区段。
- 允许的格式变化；禁止修改系统代码、测试、数据库、正式数据和未授权文档。
- 交付前执行 `git diff --check`，检查 diff 只包含授权文件，并报告实际 diff 路径。
- HTML 文档必须检查 `</body>`、`</html>`、新增锚点和目录链接；Markdown 必须检查代码块闭合和路径可读性。

## 6. 浏览器真实操作协议

1. P1 先读取并确认服务进程身份、`127.0.0.1:8787`、数据根和三个健康端点；端口监听、旧 PID 文件或页面能打开都不能单独证明服务就绪。
2. 使用 Prompt 指定的可视浏览器。打开页面后记录完整 URL、页面标题和关键可见文本；不要用 DOM 清单替代点击。
3. 对安全导航/只读按钮逐项真实点击。对保存、提交、导入、归档、删除、永久删除、下载、Provider 测试、配置保存逐项按授权执行；未授权的控件只记录为 `NOT_VERIFIED`，不点击。
4. 每次动作后按指定等待条件确认结果，再保存截图和日志。点击没有可观察变化时记录 `FAIL`，不得把“点击事件已发出”写成通过。
5. 需要真实 Provider、OCR、ASR、Email 或飞书时，Prompt 必须同时提供精确配置、最小合成输入、调用范围和交付授权。缺一项即 `BLOCKED`；不得使用 fake-provider 冒充真实能力，也不得发送外部消息。
6. 浏览器证据只能证明本次精确 URL、数据根、输入和步骤；不得推广成全系统 `real-pass`。
