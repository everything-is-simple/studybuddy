## 文档化的关键技术契约

1. **装配机制**（_legacy.py）: 18 分片符号交叉注入
   （setdefault），分片只依赖 _legacy_runtime，互不 import
2. **修订指纹**: 四字符字面量 `\x1f` 分隔符（非 0x1F 控制字符），
   与 migrations/_v14 必须一致
3. **检索契约**: top_k [1,50]、稳定排序 round(score,12)+chunk_id、
   retrieval_run 持久化供引用溯源、向量失败回退词法
4. **幂等体系**: 材料/卡片/练习/笔记/转录/QA 全链路幂等指纹 +
   冲突 fail-fast（key_mismatch/in_progress/mode_mismatch）
5. **源快照冻结**: 练习提交时冻结源信息，后续变更不影响历史
6. **级联刷新**: 软删除/修订变更触发全链路 stale 标记
   （卡片引用/学习源链接/9C 会话源/采集源状态）
7. **用户编辑保护**: user_edited=1 的记录永不静默覆盖
8. **进度事件溯源**: 进度汇总是事件投影，不存冗余计数
