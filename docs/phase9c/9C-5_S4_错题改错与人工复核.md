# 9C-5 S4 错题改错与人工复核

```text
执行 Phase 9C-5：实现 S4 ErrorFixer backend workflow，严格基于真实 attempt/grading/review 事实，不重写历史。

定义并实现错题进入条件：deterministic incorrect、pending_review 的人工决定、用户显式标记等必须区分；不得把 provider 建议或模糊答案自动当作错误事实。错题应有可审计 lifecycle（open/in_review/fixed/archived 等以 9C-1 为准）、安全原因/建议、citation/source status 和 weak-point 关联。重做永远创建新 attempt；修复/关闭操作不能删除或修改原 attempt、评分或人工 review。

覆盖 focused tests：错题归并、重复 attempt、reopen/fixed、人工复核状态、uncertain、privacy、source lifecycle、rollback、backup-friendly persistence。只实现 backend domain/repository 及测试，不实现 S5/UI/API 总收口。状态为 implemented/backend-pass。
```
