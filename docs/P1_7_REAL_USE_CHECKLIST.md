# P1-7 真实自用观察清单

## 观察期设置

- **开始日期**：`YYYY-MM-DD`
- **结束日期**：`YYYY-MM-DD`（建议 2-4 周）
- **观察人**：项目维护者
- **目标**：发现真实使用中的功能缺失、操作不便、性能问题、错误或用户体验问题

## 每周必做场景

### 第一周：导入与理解

- [ ] **场景 1.1：材料导入**
  - 导入 2-3 个真实学习材料（PDF/TXT/Markdown，总量建议 50-200 KB）
  - 确认解析状态、索引状态、文本预览正确
  - 记录耗时：导入 ____ 秒，索引 ____ 秒
  - **问题记录**：

- [ ] **场景 1.2：材料搜索**
  - 用 2-3 个关键词搜索已导入材料
  - 确认能找到预期材料，snippet 正确高亮
  - **问题记录**：

- [ ] **场景 1.3：Q&A 提问**
  - 对导入材料提 5-10 个真实问题（简单事实、概念解释、对比分析各 2-3 个）
  - 确认每个回答带有引用，点击引用能定位到原文
  - 记录回答质量：准确 ____ 个，部分正确 ____ 个，错误/无关 ____ 个
  - **问题记录**：

### 第二周：计划与生成

- [ ] **场景 2.1：学习计划**
  - 创建 1 个学习计划（包含 1 个目标、2-3 个模块）
  - 添加依赖关系（如果适用）
  - 设置学习节奏（每周目标）
  - 确认进度显示正确
  - **问题记录**：

- [ ] **场景 2.2：笔记生成**
  - 为 1-2 个材料生成笔记（选择提纲或详细笔记）
  - 确认生成的笔记内容合理，引用材料正确
  - 编辑并确认 1 条笔记
  - **问题记录**：

- [ ] **场景 2.3：卡片/练习生成**
  - 为 1-2 个材料或模块生成复习卡片或练习题（各 3-5 个）
  - 确认生成的卡片/题目质量可用
  - 编辑并确认 2-3 个卡片/题目
  - **问题记录**：

### 第三周：练习与反馈

- [ ] **场景 3.1：练习会话**
  - 完成 1-2 次练习会话（每次 5-10 题）
  - 确认题目显示、作答、提交、正确答案展示流程顺畅
  - 记录练习结果：正确率 _____%，耗时 ____ 分钟
  - **问题记录**：

- [ ] **场景 3.2：错题复习**
  - 查看练习结果和错题列表
  - 对 2-3 道错题"再次练习"
  - 确认二次作答能正确记录
  - **问题记录**：

- [ ] **场景 3.3：弱点汇总**
  - 查看"弱点"页面，确认识别的薄弱知识点合理
  - 针对 1 个弱点生成专项练习或复习卡片
  - **问题记录**：

### 第四周：报告与维护

- [ ] **场景 4.1：进度报告**
  - 生成 1 次每周报告（选择过去 7 天）
  - 确认报告内容包含：活跃目标、练习统计、弱点、有效来源
  - 导出为 JSON 和 Markdown，确认格式正确
  - **问题记录**：

- [ ] **场景 4.2：材料管理**
  - 删除 1 个材料，确认进入回收站
  - 从回收站恢复该材料
  - 重命名 1 个材料，确认搜索和引用更新
  - **问题记录**：

- [ ] **场景 4.3：配置检查**
  - 检查 Provider 配置状态（设置页面）
  - 检查任务列表（确认无卡住的任务）
  - 检查存储空间（`data_root` 大小合理）
  - **问题记录**：

## 注意事项

### 使用原则

- **真实材料**：使用自己的实际学习材料，不要用测试数据
- **正常节奏**：按真实学习节奏使用，不要为了完成清单而赶进度
- **及时记录**：遇到问题立即记录，不要事后回忆
- **保持诚实**：记录真实感受，不要因为是自己的项目而美化问题

### 数据安全

- 观察期使用的 `data_root` 应该是独立的测试目录（建议 `H:/studybuddy-self-use`）
- 不要用包含敏感信息的材料进行观察
- 观察期结束后备份数据库用于复现问题

### 终止条件

如果观察期内发现严重阻塞问题（P0），应立即终止观察，修复问题后重新开始观察期。
