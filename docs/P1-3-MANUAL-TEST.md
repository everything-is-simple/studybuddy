# P1-3 手动测试指南

## 目标
验证 Cards 和 Exercises 的核心用户流程是否在浏览器中正常工作。

## 准备工作

### 1. 启动服务器
```bash
cd H:\studybuddy\backend
set STUDYBUDDY_DATA_ROOT=H:\studybuddy-test\manual
set STUDYBUDDY_AI_PROVIDER=fake
C:\miniconda\py310\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

### 2. 打开浏览器
访问：http://127.0.0.1:8000/

## 测试场景

### 场景 1：卡片管理完整流程

#### 1.1 创建卡片组
1. 访问 http://127.0.0.1:8000/app/cards.html
2. 在"新卡片组名称"输入框输入：`测试卡片组`
3. 点击"创建卡片组"按钮
4. **预期结果**：卡片组列表中出现"测试卡片组 0 张卡片 进行中"

#### 1.2 创建手动卡片
1. 点击刚创建的卡片组
2. **预期结果**：右侧显示"测试卡片组"标题和卡片创建表单
3. 在"问题"输入框输入：`什么是 StudyBuddy？`
4. 在"答案"文本框输入：`一个学习材料管理系统`
5. 点击"创建卡片"按钮
6. **预期结果**：
   - 显示"卡片已创建"成功消息
   - 卡片列表中出现新卡片
   - 卡片组计数更新为"1 张卡片"

#### 1.3 查看卡片详情
1. 点击刚创建的卡片项
2. **预期结果**：
   - 右侧显示卡片详情
   - 显示"问题：什么是 StudyBuddy？"
   - 显示"答案：一个学习材料管理系统"
   - 显示状态标记（草稿）

#### 1.4 编辑卡片
1. 在卡片详情中，修改问题为：`StudyBuddy 是什么？`
2. 点击"保存卡片"按钮
3. **预期结果**：
   - 显示"卡片已保存"成功消息
   - 卡片列表中的标题更新为新问题

#### 1.5 确认卡片
1. 在卡片详情中，点击"确认卡片"按钮
2. **预期结果**：
   - 显示"卡片已确认"成功消息
   - 状态从"草稿"变为"就绪"
   - 出现"记为掌握"和"需要复习"按钮

#### 1.6 记录复习
1. 点击"记为掌握"按钮
2. **预期结果**：显示"复习记录已保存"成功消息

## 常见问题排查

### 问题 1：点击卡片/题目后详情区域为空
**可能原因**：
- API 调用失败
- 前端 JavaScript 错误

**排查步骤**：
1. 打开浏览器开发者工具（F12）
2. 查看 Console 标签页是否有 JavaScript 错误
3. 查看 Network 标签页，找到失败的 API 请求
4. 检查请求的状态码和响应内容

### 问题 2：创建后列表没有更新
**可能原因**：
- API 创建失败
- 列表刷新逻辑问题

**排查步骤**：
1. 检查 Network 标签页中的 POST 请求是否成功（状态码 201）
2. 手动刷新页面，看列表是否显示新创建的项
3. 检查浏览器 Console 是否有错误消息

### 问题 3：显示"请求失败，请重试"
**可能原因**：
- 后端 API 返回错误
- 网络问题

**排查步骤**：
1. 查看 Network 标签页中失败请求的响应
2. 检查后端服务器日志
3. 确认 API 端点路径是否正确
