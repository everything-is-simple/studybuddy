0. 开始使用 启动与入口

StudyBuddy 是一个本地单进程、单实例系统：启动服务后，功能在浏览器里完成，数据只存在你自己的电脑上。启动只需一条命令——在项目目录执行 python -m backend.app serve，并确认 /api/liveness、/api/health、/api/readiness 后，用浏览器打开 http://localhost:8787/app/today.html 即可进入"今天"首页。页面能打开不等于服务已就绪；页顶导航条固定在所有页面上，"更多"按钮可展开页面入口。关闭命令行窗口（或 Ctrl+C）服务即停止，数据不会丢失。

  1. 启动服务：命令行执行 python -m backend.app serve，等待就绪。
  2. 打开首页：浏览器访问 localhost:8787/app/today.html。

1. 今天（首页） today.html

"今天"是每天打开 StudyBuddy 的第一站：上半部分是今日概览（今日该学的任务、材料与练习状态），中部是近七天学习趋势图，下方列出今日任务清单，点任何一条任务即可直接跳到对应页面去做。"管理计划"按钮通向计划页；如果页面加载失败（例如服务刚重启），点"重新加载"即可恢复。建议每天从这里开始，先看任务、再动手。

  1. 看今日概览：了解今天有哪些事等着做。
  2. 看七天趋势：确认近一周的学习节奏是否稳定。
  3. 点今日任务：直接跳到对应页面执行；点管理计划可调整计划。

2. 资料（导入与管理） materials.html

"资料"是整个系统的起点：所有学习材料（教材 PDF、讲义、笔记文件等）从这里批量导入。系统会自动解析文本并显示每份材料的状态（成功 / 空文件 / 失败），选中材料后可以一键"前往问答"。导错的材料删除后会进入回收站，点"查看回收站"还能找回来。支持 TXT / MD / PDF / DOCX / PPTX；旧版 DOC、RTF、旧版 PPT 会被明确拒绝，请先另存为新格式再导入。

  1. 点选择文件夹导入，一次选中整个文件夹批量导入。
  2. 用状态筛选 + 应用筛选，快速找出"失败 / 空文件"的材料处理。
  3. 点击材料行进入材料详情查看解析结果。
  4. 选中材料后点前往问答，直接基于它开始提问。
提示：删除材料不会立即消失，先在回收站；确认格式被拒绝时，把文件另存为 PDF / DOCX / PPTX / TXT / MD 再导入。

3. 材料详情 material-detail.html

从资料列表点进来的单份材料工作台：上半部分显示处理状态与解析出的正文，可以"导出解析文本"带走或"下载原文件"对照。核心动作是建索引——点"建立 AI 索引"或"加入索引任务"后，系统先对正文切分；只有 Embedding 已配置且可用时才会生成向量，问答可用的检索模式以页面能力状态为准。切分或索引进度可在"任务"页观察。页面下方的"计划关联"区还能把材料"关联到学习项"，让它在学习计划里占一个位置。

  1. 点建立 AI 索引（或排队时选加入索引任务）。
  2. 查看解析正文与分块 / 向量计数，确认索引完成。
  3. 需要时在计划关联区把材料挂到某个学习项。

4. 问答 qa.html

"问答"是学习的主战场：针对已建索引的材料提问，回答会附带引用（能点回原文出处）。提问前先设好"材料范围"和当前能力支持的检索模式：有 Embedding 且页面显示可用时才选择"混合"或"向量"，否则使用可用的词法模式；词法适合精确术语，向量适合换说法的提问。如果当前材料还没索引，点"索引当前材料"先补上。然后输入问题"提交问题"即可；一轮聊完点"新对话"开新话题，历史问答都留在"问答历史"里可回看。

  1. 选材料范围与当前能力支持的检索模式；有 Embedding 时可选"混合"。
  2. 输入问题后点提交问题，等待带引用的回答。
  3. 点回答里的引用编号核对原文；换话题点新对话。历史记录点击查看对话与引用行内展开；点关闭对话详情或再次点展开按钮可收起，焦点返回展开按钮，回答和引用仍保留。

5. 学习笔记 notes.html

"笔记"页管理学习过程中的两种笔记：你自己手写的"用户笔记"，以及 AI 根据材料生成的"AI 草稿"。AI 草稿必须经过你确认后才会转为正式笔记——AI 永远不会静默覆盖你写过的内容。新建时在表单里填好内容点"新建用户笔记"；想让 AI 起草就点"生成 AI 草稿"，确认后生效；材料、问答片段都可以"关联到当前笔记"留证据。勾选"显示已归档笔记"可以翻出归档内容。

  1. 表单填写后点新建用户笔记，立即保存。
  2. 要 AI 起草就点生成 AI 草稿，阅读后点确认采纳才转正。
  3. 在笔记列表点击进入详情，可继续关联材料 / 问答片段。

6. 笔记详情 note-detail.html

从笔记列表点进来的单条笔记视图：这里能看到笔记类型（用户笔记还是 AI 确认稿）、完整内容，以及最重要的"来源状态"——这条笔记关联了哪些材料、哪些问答引用，保证每条笔记都有据可查。日常用法：复习前打开笔记详情，顺着来源链接把原文重读一遍；发现内容过时就回到列表新建或修改。本页以查看为主，不需要复杂操作。

  1. 从笔记列表点击进入本页，核对类型与内容。
  2. 顺着来源状态里的链接回看材料原文或问答。

7. 学习计划 plans.html

"计划"页把学习目标拆成可执行的层级：先"新建目标"（例如"期中提分"），再在目标下"新建模块"（例如"语文基础"），最后为模块"新建计划草稿"排学习项。每条计划都可以"添加来源链接"，把材料或笔记挂上去，学习时一键跳转。列表里能看到各计划草稿的进度；也可以从"今天"页的"管理计划"按钮直接进入本页。

  1. 点新建目标写下大方向。
  2. 在目标下点新建模块划分科目或板块。
  3. 点新建计划草稿，把学习项排进模块。
  4. 用添加来源链接给学习项挂上材料或笔记。
页面有防抖保护：连续快速点击按钮可能被静默忽略，等绿色成功提示出现再进行下一步。

8. 计划详情 plan-detail.html

从计划列表点进来的单个计划草稿工作台：这里罗列该计划的全部学习项，每项都有来源链接（跳回材料或笔记）与完成状态。学习推进中最大的诉求是"进度准不准"——点"刷新进度"即可按最新完成情况重算，"今天"页的概览也随之更新。日常节奏：每天打开计划详情 → 看今天该做哪几项 → 去做 → 回来刷新进度。

  1. 按学习项顺序去学，顺着来源链接打开材料。
  2. 完成情况变化后点刷新进度，保持统计准确。

9. 卡片 cards.html

"卡片"页管理记忆卡片：先"创建卡片组"（按科目或单元分组），再在组内"创建卡片"（正反面问答式）。懒得手写可以点"生成卡片草稿"让 AI 从材料里起草——同样需要你确认后才会成为正式卡片。已确认的卡片进入复习队列，按遗忘规律安排重现。点"刷新"同步最新状态。建议：每学完一个单元就建一组卡片，积累成个人题库。

  1. 点创建卡片组建立分组。
  2. 组内创建卡片，或用生成卡片草稿+确认批量起草。
  3. 点卡片组的开始复习进入记忆复习。

10. 题目（练习集） exercises.html

"题目"页是题库管理中枢：以"练习集"为单位组织题目，支持选择题、判断题、简答题三种题型。手工出题用"创建练习集"+"创建题目"；想省事就"生成题目草稿"，AI 会依据你选的材料出题，确认后入库——和卡片一样，草稿必须经你确认。题目就绪后，到"练习"页开一场限时练习来消耗这些题。点"刷新列表"同步最新数据。

  1. 点创建练习集建立题库容器。
  2. 创建题目逐题录入，或生成题目草稿后确认入库。

11. 练习 practice.html

"练习"页是限时训练的调度台：上方可"创建冲刺目标"（例如"本周完成 5 次练习"），中部是系统按你的弱点和题库给的"推荐练习"，点"刷新推荐"可以换一批；准备好了就"创建练习会话"进入答题。下方"错题库"汇总历次做错的题，是复习的黄金材料——错题会同时出现在"复盘"页。整个闭环：出题（题目页）→ 练习（本页）→ 结果（结果页）→ 复盘（复盘页）。

  1. 可选：先创建冲刺目标给一周定个量。
  2. 刷新推荐挑选合适的题组。
  3. 点创建练习会话开始限时答题。
  4. 抽空翻错题库，把错题重练一遍。

12. 答题会话 practice-session.html

从"练习"页进入后的逐题答题页：一屏一题，顶部有剩余时间与进度（第几题 / 共几题），做完一题点"提交答案"立即记录，用"上一题""下一题"来回检查。全部答完后系统自动跳转到结果页——不需要手动收卷。限时设计的意义在于模拟考场节奏：先做完、再回头检查，不会的题也要先给出一个答案。

  1. 读题并作答，点提交答案记录本题。
  2. 用上一题 / 下一题检查修改。
  3. 全部答完自动跳转练习结果页。

13. 练习结果 practice-result.html

每场练习结束后的结算页：上半部分是结果摘要（得分、正确率、用时、各题型表现），下半部分是 AI 生成的练习反馈——只呈现"允许公开"的反馈内容，涉及具体原文或隐私的部分不会展示。这是整条练习链路的落点：错题从这里流向"错题库"与"复盘"页，弱点数据流进"报告"页的统计。看完成绩别急着关，先扫一眼反馈里的建议，决定下一步练什么。

  1. 看摘要：得分、正确率、用时。
  2. 读AI 反馈（仅公开内容），按建议安排下一步。
  3. 错题自动进入错题库，到复盘页集中处理。

14. 复盘（错题与薄弱点） review.html

"复盘"页是练习链路的收尾反思区：左边是"错题清单"——每一道做错的题都在这里排队等你重做；右边是"薄弱点汇总"——系统按知识点归纳你反复失分的区域，比单看错题更能指明方向。列表长就点"加载更多"；想立刻重练某道题，点"返回练习"回练习页开会话。建议固定节奏：每次练完当天复盘一次，周末再统一重练本周错题。

  1. 过一遍错题清单，逐题弄懂错因。
  2. 看薄弱点汇总，优先攻克失分最多的知识点。
  3. 列表长点加载更多；要重练点返回练习。

15. 报告 reports.html

"报告"页把一段时间的学习数据汇总成可带走的文档：先选时间范围（快捷按钮"今天 / 本周 / 本月"），再选报告类型，点"生成报告"等待产出，然后"刷新报告预览"查看内容。满意后用"导出 JSON"或"导出 Markdown"保存到本地。注意两点：报告已做脱敏处理（不含原始材料全文与隐私）；报告不会自动发送给任何人——外发属于单独授权的功能，默认关闭。

  1. 点快捷范围今天 / 本周 / 本月，选好报告类型。
  2. 点生成报告，完成后点刷新报告预览查看。
  3. 满意则点导出 JSON / 导出 Markdown 存档。

16. 课堂采集与报告 classroom.html

"课堂采集"是有条件的扩展能力：在 capture.html 创建会话、上传原件并发起 OCR/ASR，系统先生成可编辑草稿；确认后才转为学习材料。classroom.html主要用于刷新会话、查看转写稿和脱敏报告，转写文本确认后才能按普通材料参与后续流程。OCR/ASR 未配置或只有演示状态时，应跳过真实质量判断；它不是首次使用的前置流程。

  1. 点刷新采集列表同步所有采集会话。
  2. 点击会话查看转写文本与学习报告。

17. 新建采集会话 capture.html

"采集会话"页是课堂采集的发起点：填会话类型、会话名称和媒体类型，点"创建"生成会话。创建后在该会话的详情区域上传媒体、发起 OCR/ASR，并在草稿区编辑、确认或拒绝；classroom.html用于查看已创建的会话和报告。一节课对应一个会话，命名建议带日期，方便日后检索。

已确认或已拒绝的会话可在详情点归档采集，确认后从默认列表隐藏；取消确认不改变会话。勾选显示已归档可查看归档记录，原件、转写内容和已确认的学习材料均保留。尚未完成审阅或正在转写的会话不能归档；当前没有恢复归档入口。

  1. 填类型 / 名称 / 媒体类型三项。
  2. 点创建，随后点刷新确认会话出现。

18. 任务状态 tasks.html

"任务"页只显示当前已接入任务 runner 的操作记录，最常见的是 Embedding 索引任务。用"应用筛选"按状态过滤（排队 / 进行中 / 成功 / 失败），点"刷新"获取最新进度；卡住或失败的任务是否支持取消/重试，以任务详情提供的动作和错误状态为准。课堂 OCR/ASR、问答、报告生成不会因为页面存在就自动进入这个队列，不能把任务页当作所有后台工作的总览。

  1. 应用筛选聚焦某个状态的任务。
  2. 点刷新看实时进度（如分块 12/24）。
  3. 失败任务在详情区点重试；不再需要的点取消（均有确认弹窗）。

19. Provider 设置 settings-provider.html

"Provider 设置"配置 StudyBuddy 背后的 AI 与 Email 连接：填好 API 地址、密钥、模型名后可先点"测试 Provider 连接"，通过后再点"保存此配置"。连接测试只证明本次协议/连通性检查，不证明真实问答质量、Embedding 质量或长期可用性；页面使用 synthetic payload，不发送学习材料。配置串可复制到剪贴板，但不要复制到聊天、截图或 Git。保存的凭据存在本地 data_root 配置文件中；Email/Feishu 报告外发默认关闭，属于独立授权和专项验收。

  1. 填API 地址 / 密钥 / 模型名。
  2. 需要使用真实 Provider 时，点测试 Provider 连接并记录本次结果；“成功”不等于真实能力已通过。
  3. 确认配置边界后再点保存此配置；配置串不要通过聊天、截图或 Git 流转。

20. 系统设置 settings.html

"系统设置"显示七项能力（导入解析、OCR、ASR、索引、问答、生成、报告）的探测和配置状态。"available/configured"表示探测或配置条件，不等于真实 Provider、模型质量或完整用户路径已验证；真实能力应按专项证据标记为 real-pass 或 not_verified。状态可疑就点"重新自检"或"刷新状态"；这里也能集中保存或清除 AI 与 Embedding 配置。排障口诀：问答答不了 → 先看能力状态，再去 Provider 设置查连接和材料索引。

  1. 进页面先看七项能力自检面板。
  2. 状态可疑点重新自检 / 刷新状态。
  3. 改完 AI / Embedding 配置点保存并生效（免重启）。
主流程一图记牢：启动服务 → 资料导入材料 → 材料详情建索引 → 问答带引用提问 → 笔记 / 卡片 / 题目沉淀 → 练习限时答题 → 结果 / 复盘找薄弱 → 报告导出存档。卡在任何一步，去任务页和系统设置页找原因。
