# Phase 9A Prompt 包：学习领域基础与计划核心

- `00_COMMON_CONTEXT.md`：所有任务共用的项目背景、治理约束和执行规则。
- `00_MASTER_PLAN_PROMPT.md`：Phase 9A 总规划 prompt，只规划不实现。
- `9A-0_*.md` 至 `9A-8_*.md`：每个子任务独立 prompt。
- `EXECUTION_ORDER_AND_GATES.md`：执行顺序、提交拆分和完成门槛。
- `PHASE9A_DOMAIN_CONTRACT.md`：9A-0/9A-1 契约、9A-2 schema、9A-3 repository/domain、9A-4 API 和 9A-5 browser-pass implementation record。

推荐顺序：9A-0 → 9A-1 → 9A-2 → 9A-3 → 9A-4 → 9A-5 → 9A-6 → 9A-7 → 9A-8。

每次只执行一个子任务。目录整体仍是 `planned` 的执行包；各子任务状态以 `docs/STATUS.md` 和 `PHASE9A_DOMAIN_CONTRACT.md` 为准，prompt 和设计不是实现证据。
