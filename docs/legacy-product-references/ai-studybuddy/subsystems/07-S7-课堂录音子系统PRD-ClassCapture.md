# S7 课堂采集子系统 ClassCapture PRD

**版本**：v0.3
**日期**：2026-07-25
**状态**：S7-MVP 已完成主线复验并推送 `origin/master`；旧 T02/T04 外置候选能力为 `PARTIAL`、T03 Composer smoke 为 `PASS`，均不等于完整 S7、通用静音、G2、T02 主线、用户机验收或 Phase 3
**定位**：把学生已获允许的短课堂录音在本机转为可编辑文字，并显式交给既有 S2 NoteBuilder 文本资料入口

---

## 1. 为什么现在做

课堂讲解常包含教材之外的重点、例题思路和考试提示。学生不能一边听课一边完整记录，课后重听又耗时。当前系统已具备 S2 的文本资料与笔记能力，因此最有价值、最小且可验证的下一步是：把一段本地课堂录音变成学生可修改的文字，再交给 S2，而不是先建设完整媒体平台。

S7 服务于学生本人：她决定是否录音、是否已获得允许、是否转写、如何修改文本、是否保存为学习资料和是否进一步生成笔记。它不是课堂监听、教师/同学监控或云端采集系统。

---

## 2. S7-MVP 产品合同

### 2.1 唯一主流程

```text
学生在已选课程的资料页
  → 勾选“已获老师和相关同学允许，仅用于本机学习整理”
  → 选择受控 PCM WAV
  → 同步调用显式配置的本机 whisper.cpp
  → 返回可编辑转写文本
  → 学生修改并点击“保存为 S2 笔记输入”
  → 创建 S2 text material + normalized_text
  → 学生随后自行点击现有 S2 的“生成笔记”
```

### 2.2 受控输入

第一版只支持：

- `.wav` / `audio/wav`；
- RIFF/WAVE container；
- PCM、16 kHz、单声道、16-bit；
- 由 `LOCAL_ASR_WHISPER_MAX_FILE_BYTES` 限定的短文件。

服务端不信任浏览器 MIME，必须重新验证文件头和 WAV 格式。未配置本机 CLI 或模型、格式不符、文件过大、超时或 CLI 失败时，返回稳定、不泄漏路径与全文的错误。

### 2.3 可编辑与 S2 handoff

- 转写成功不自动保存，学生可先修改；
- 只有学生显式保存才创建 S2 `file_type='text'` material 与 `normalized_texts(source_type='class_audio_transcription')`；
- 保存不创建 S7 Job、`material_convert` Job 或 `note_generate` Job；不自动调用 Provider；
- S2 的笔记生成仍是学生随后在既有资料卡上的一次明确动作。

## 3. 质量、许可与隐私

- 首次入口必须显示并要求确认：**“我确认这段课堂录音已获得老师和相关同学允许，仅用于本机学习整理。”**
- 提示：静音、多人重叠说话、噪声、低音量、方言或设备质量可能造成漏字、错字或无意义文本；学生需要校对。
- 固定候选的精确全零 PCM 可由外部 harness 前置识别为 `NO_SPEECH`，不代表模型对所有静音或无语音内容可靠；产品不得作通用 no-speech 承诺。
- 原始音频只可暂存于 `APP_DATA_ROOT/tmp/class-capture/<request-id>/`；成功、失败、超时和取消都在 `finally` 清理。
- 原始音频、转写全文、原始文件名、CLI/模型路径、stdout/stderr、密钥和正式数据不进入普通日志、StudyEvent、S6 报告或浏览器 `localStorage`。
- 默认不上传云端，不调用 Provider；未来任何云端 ASR 都必须独立进行产品、隐私、配置和验收决策。

## 4. 技术与责任边界

| 层                         | S7-MVP 责任                                                               | 不负责                                           |
| -------------------------- | ------------------------------------------------------------------------- | ------------------------------------------------ |
| 前端资料页卡片             | 许可确认、WAV 选择、质量提示、转写结果编辑、显式保存                      | 浏览器录音、实时进度、持久化全文                 |
| `ClassCaptureService`      | 请求校验、课程/学期归属、协调转写与 S2 handoff                            | Worker/队列、媒体库                              |
| `WhisperCppAuralConverter` | 显式配置 CLI/模型、参数数组进程调用、超时、固定错误、临时文件清理         | 下载模型、猜路径、网络/Provider fallback         |
| S2 NoteBuilder             | 保存学生确认的 `text` material 与 `normalized_text`，沿用既有生成笔记动作 | 录音解析、ASR、长期音频存储                      |
| 外置候选目录               | 仅供受控运行时配置引用，允许开发机脱敏 smoke                              | 进入 Git、复制进 `packages/`、成为用户机验收替代 |

业务代码不得硬编码 `H:\...`；只能通过 `env.ts` 的 `LOCAL_ASR_WHISPER_*` 配置与 `paths.ts` 的 `APP_DATA_ROOT` 派生路径工作。

## 5. 非目标与后续路线

本 MVP **不做**：

- MP3、M4A、WebM、视频、FFmpeg 转码；
- 实时录音、流式字幕、课堂监听；
- 说话人分离、身份识别、声纹；
- 云端上传、Provider、SMTP、飞书；
- Firewall、G2、Docker、WSL；
- S7 持久化 Job/Worker、新音频表、原始音频留存；
- 用户电脑验收或 Phase 3。

未来如确需长音频、更多格式、后台任务、视频、说话人分离或安全/网络门禁，必须按独立任务重新定义产品价值、隐私、运行时、测试和用户验收；不得借本 MVP 自动进入。

---

## 6. 验收标准

只有下列全部满足且经主线复验、推送 `origin/master` 后，才能把 S7-MVP 标为完成：

1. 在既有课程资料页可完成许可确认、受控 WAV 选择、转写、编辑和显式保存为 S2 文本资料；
2. 后端只从显式环境变量获取 CLI/模型，未配置时不猜路径、不回退云端；
3. 格式、大小、超时、进程失败和运行时不可用均有稳定错误；
4. 成功及失败路径均清理临时文件和 CLI 进程；
5. S2 handoff 不保存原始录音、不创建转换/笔记 Job、不自动调用 Provider；
6. 后端真实 SQLite/API、前端和浏览器 fake-CLI 闭环通过；开发机固定真实 CLI 的脱敏 smoke 通过；
7. `pnpm type-check`、前后端 build、测试、文档治理和 `git diff --check` 通过；
8. 文档与 `docs/04` 如实记录证据，并保留完整 S7、G2、用户机验收、Phase 3 的未完成边界。
