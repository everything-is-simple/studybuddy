第 0 课 · 先准备

开始与能力检查

StudyBuddy 是运行在自己电脑上的本地学习资料系统。它不是云端协作平台，当前按“本机、单进程、单实例、本地磁盘”使用。

今天的目标：启动服务，打开首页，知道哪些能力已经可用。第一次请使用一份不敏感、较短的测试资料。

启动

在项目目录执行项目提供的启动脚本；开发时也可以使用：

python -m backend.app serve

服务启动后打开 http://127.0.0.1:8787。先确认 /api/liveness、/api/health 和 /api/readiness 能按预期返回，再开始导入；页面能打开不等于服务已经就绪。不用时，用项目的停止脚本停止对应实例，不要随意结束其他 Python 进程。

把第一份资料放进系统

完成后你会得到：一份状态为成功、正文可见、可以搜索和导出的学习材料。

图 1-1　先导入，再根据状态处理；材料行可以进入材料详情。

  1. 打开“资料”，选择一份小的 TXT、MD、PDF、DOCX 或 PPTX 文件；也可以选择文件夹导入。
  2. 等待结果，确认材料状态为“解析成功”，再点击材料行进入详情。

卡住时：旧版 DOC、旧版 PPT、RTF 会被拒绝；空文件会显示空状态；损坏或过大的文件请先换一份小的标准格式文件。不要把“格式拒绝”当成 AI 配置问题。
场景二 · 问答

让系统回答，并核对引用

StudyBuddy 的问答不是“输入问题就直接回答”。正确顺序是：材料先建立索引，回答后再沿引用核对原文。

完成后你会得到：一个带引用的回答，并能点击引用回到材料正文位置。

图 2-1　先完成索引，再按能力选择检索模式并核对引用。

  1. 在材料详情点击“建立 AI 索引”。材料较大或希望排队处理时，使用“加入索引任务”；正文切分可以先完成，生成向量需要 Embedding 已配置且可用。
  2. 索引完成后进入“问答”，选择材料范围；有 Embedding 时可选“混合”或“向量”，否则按页面提示使用可用的词法模式。
  3. 提出资料中能直接找到答案的问题，例如“这一节列出了哪三个要点？”。
  4. 阅读回答，点击引用编号，确认它确实回到正确的材料正文。
两个索引按钮的区别：“建立 AI 索引”是立即执行；“加入索引任务”是进入当前已接入的向量索引任务队列。任务页目前主要展示 embedding_index，课堂转写、问答和报告生成不会自动出现在这个队列里。
完成标志：回答有引用，点击引用能定位到材料内容；没有引用时，不要把回答当作已核实结论。
卡住时：先到“系统设置”看 AI Provider 和 Embedding，再确认材料索引状态。Provider 未配置、材料未索引或没有可引用内容时，页面会提示原因。
场景三 · 沉淀

把答案变成自己的笔记和卡片

问答解决“现在理解”，手工笔记帮助你“以后记住”。卡片 AI 草稿属于可选能力，必须先读、再确认。

完成后你会得到：至少一条自己的学习笔记；卡片只在 Provider、索引和来源条件都满足时继续。

图 3-1　手工笔记可以立即保存；AI 生成内容必须先读、再确认。

  1. 打开“笔记”，填写标题和内容，点击“新建用户笔记”。
  2. 打开笔记详情，查看类型、内容和来源状态；顺着来源回到材料核对。
  3. 需要时进入“卡片”，创建卡片组，手工创建卡片，或选择材料生成 AI 卡片草稿。
  4. 只确认自己检查过的草稿。确认后卡片才进入复习流程。
记住：AI 生成的是草稿，不是自动正确的知识。草稿必须经过人工阅读和确认，不会自动覆盖已经确认的内容。
完成标志：你能独立写一条笔记，并知道如何从笔记来源回看原文。卡片草稿的完成标志另行按“草稿 → 阅读/编辑 → 确认”验收。
场景四 · 练习

做一次练习，再完成复盘

这是完成资料问答后可继续的学习闭环：准备题目、答题、看结果、处理错题。手工题目不需要真实 AI，因此不阻塞首次资料验收。

完成后你会得到：一次练习会话的结果，以及可以继续处理的错题或薄弱点。

图 4-1　题目准备好后进入练习会话，结果页再进入复盘。

  1. 打开“题目”，创建练习集，再手工创建一道选择题、判断题或简答题；也可以确认一条 AI 草稿。
  2. 打开“练习”，选择可用题目，创建练习会话。
  3. 在答题会话中逐题作答并点击“提交答案”；完成后进入练习结果。
  4. 在结果页查看得分、已评分数量、已提交数量、错题数量和“进入复盘”入口。
  5. 打开“复盘”，查看错题和薄弱点；简答题可能需要人工复核，不要把所有简答题理解成自动判分。
完成标志：至少提交一道题，能打开练习结果，并能进入复盘查看错题或薄弱点。
说明：练习结果页当前以真实页面显示的摘要为准，不承诺固定出现各题型统计或 AI 反馈。AI 出题还需要 Provider、索引和有效来源。
扩展能力 · 有条件使用

按需处理课堂录音或板书图片

当你熟悉资料和练习后，再来尝试课堂采集。它采用“先草稿、后确认”的方式，上传不会直接把内容变成正式学习材料。

完成后你会得到：一份经人工核对并确认的课堂转写或 OCR 材料。

音频建议 .wav / .mp3 / .m4a；图片建议 .png / .jpg / .webp。

图 5-1　创建、上传、转写/识别、编辑和确认都在采集会话详情中完成。

  1. 进入“课堂采集”，点击“新建采集会话”，填写类型、名称和媒体类型。
  2. 打开刚创建的会话，在会话详情中上传音频或图片。
  3. 点击“开始转写（ASR）”或“开始识别（OCR）”，等待草稿出现。
  4. 核对并编辑草稿；确认无误后点击“确认转为学习材料”。
  5. 需要查看历史会话、转写稿和报告时，再进入“课堂采集与报告”工作区。
入口区别：capture.html负责创建、上传、转写、编辑和确认；classroom.html主要负责查看会话、转写稿和报告。课堂转写不是当前任务页的后台任务。
完成标志：草稿经过人工核对，确认后能在“资料”中看到新的学习材料。
能力限制：没有配置 ASR/OCR 时，先在“系统设置”查看状态并跳过本扩展。状态为 configured/available 也不等于真实能力 real-pass；演示模式或隔离测试结果不代表真实语音识别或图片识别质量。
扩展训练 · 熟悉核心链路后

学习计划与报告

计划和报告是组织与复盘工具，不是第一次使用必须完成的前置步骤。

创建目标期中提分
创建计划属于目标
添加学习项可绑定模块
激活并学习记录进度
生成报告导出脱敏摘要
  1. 在“计划”创建目标；再创建计划并选择所属目标。
  2. 在计划详情添加学习项；需要按科目组织时，再把学习项绑定到模块。
  3. 确认并激活计划，学习后记录或刷新进度。
  4. 在“报告”选择日期范围和报告类型，生成本地脱敏报告，选择报告后刷新预览，再导出 JSON 或 Markdown。
报告边界：报告不会自动发送，外发默认关闭。Provider 设置的主流程是“填写 → 测试连接 → 保存此配置”；“复制到剪贴板”只是高级配置迁移选项，不是普通用户必须操作的步骤。

新手毕业

我已经能独立使用了吗？

完成前四项，就已经掌握最小核心路径；练习、课堂采集、计划和报告都是按需扩展。

训练方式：不要一次把所有页面都打开。每次只完成一个场景，并确认“完成标志”；第二天从“今天”页继续。这样可以逐渐熟悉 StudyBuddy，而不是被大量功能一次性淹没。
