# AI Agent 任务对话标准模板

> **文档性质**: AI Agent 通信协议  
> **适用场景**: 人类向 AI Agent 分配任务时的标准格式  
> **目标**: 消除歧义，防止 AI Agent 错误理解任务  
> **最后更新**: 2026-09-27

---

## 为什么需要这个模板

### AI Agent 的常见错误理解模式

| 用户说 | AI 错误理解为 | 正确理解应该是 |
|--------|--------------|--------------|
| "验证页面" | 用 curl 测试 API | 在浏览器中打开页面 |
| "测试按钮" | 读 HTML 提取按钮 ID | 真实点击按钮 |
| "模拟人类操作" | 写个测试脚本 | 用 Playwright 自动化真实浏览器 |
| "检查功能" | 只生成报告 | 执行操作并记录结果 |

### 强制使用标准模板的原因

1. **消除歧义** - 明确工具、方式、禁止项
2. **防止偷懒** - 不允许用简单方法代替复杂任务
3. **确保证据** - 必须有截图、日志等可验证产物
4. **保护环境** - 明确文件存放位置，防止污染源码
